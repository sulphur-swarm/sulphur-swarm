## What We Do

Sulphur Swarm builds **SwarmFix** — an AI-powered service that resolves GitHub issues autonomously. Submit a bug or feature request, and our AI agent swarm researches, plans, implements, and validates the fix through a multi-stage pipeline with dual verification. You get a production-ready pull request — no human engineers needed.

## How It Works

1. **Submit** — Open an issue in our [intake repository](https://github.com/sulphur-swarm/swarmfix) describing the bug or feature
2. **Swarm Resolves** — Our AI agent swarm processes the issue through research, planning, implementation, and validation stages
3. **Receive PR** — Get a tested, reviewed pull request delivered to your repository
